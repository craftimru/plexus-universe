Открыть редактор

Для сохранения правок нужен локальный сервер редактора.

Запустите edit_graph.bat в папке карты или выполните там:

python -X utf8 edit_graph.py

Редактор откроется автоматически. Если сервер уже запущен, перейдите к нему кнопкой ниже. Браузер не может сам запустить Python или BAT-файл.
