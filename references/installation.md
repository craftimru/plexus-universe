# Установка навыка

Корень репозитория является папкой навыка: `SKILL.md`, `agents/openai.yaml`, справочники, Python-команды, просмотрщик и редактор. MCP необязателен. Навык работает локально и не требует установки JavaScript-пакетов.

## Codex

Из скачанного репозитория выполните:

```sh
python -X utf8 scripts/skill_bundle.py install
```

По умолчанию копия создаётся в `~/.codex/skills/plexus-universe`. Существующий навык не перезаписывается. Для другой папки используйте `--destination PATH`.

Навык вызывается как `$plexus-universe`. Название и стартовый запрос для интерфейса находятся в `agents/openai.yaml`. Обнаружение обновлённого списка навыков зависит от приложения; если навык ещё не виден, обновите сессию агента.

## Другие агенты

Агенту, который читает навыки формата `SKILL.md`, нужна целиком папка `plexus-universe`, а не один файл инструкции. Например, папку можно установить в пользовательский каталог навыков Claude Code:

```sh
python -X utf8 scripts/skill_bundle.py install --destination "C:/Users/YOUR_NAME/.claude/skills/plexus-universe"
```

Путь зависит от агента и ОС. Автоматически настройки сторонних агентов не изменяются. Если агент не поддерживает skills, укажите ему `SKILL.md` в инструкциях проекта или подключите [MCP](mcp.md).

## Карта конкретной игры

Навык сначала ищет карту нужного проекта. Его собственная RTS-карта служит демонстрацией и не должна использоваться как описание чужой игры.

```sh
python -X utf8 /path/to/skill/scripts/project_graph.py locate --project /path/to/game
python -X utf8 /path/to/skill/scripts/project_graph.py init --project /path/to/game
```

`init` создаёт `tools/project_graph` с одним корневым узлом и переносимым относительным указанием корня проекта. Существующие игровые файлы не меняются, непустой каталог карты не перезаписывается. Можно задать `--relative tools/my_map` и `--name "My Game"`. Устанавливаются все локальные файлы инструмента и инструкция, поэтому карта остаётся работоспособной без глобальной установки навыка.

После создания агент предлагает наполнение через scoped bootstrap и осмысленно описывает узлы, а человек может открыть `tools/project_graph/edit_graph.bat` или `edit_graph.py`.

## Архив навыка

```sh
python -X utf8 scripts/skill_bundle.py package --output plexus-universe.skill
```

`.skill` — ZIP-архив с верхней папкой `plexus-universe`. Его можно импортировать в поддерживающий этот формат агент или распаковать в каталог навыков:

```sh
python -m zipfile -e plexus-universe.skill /path/to/skills
```

В архив входят только явно перечисленные файлы навыка и демонстрационные данные. `.git`, кеши, тестовые окружения, пользовательский `graph_edit.json`, его резервная копия, журнал и загруженные арты в пакет не попадают. Для переноса карты конкретного проекта переносите её рабочую папку отдельно — архив навыка предназначен для установки инструмента.

Обновляйте существующую установку осознанно: сохраните её, если в ней есть собственные изменения, и установите новую версию в свободную папку. Установщик намеренно не удаляет предыдущую копию.

## Обновление рабочей карты

Получите свежую копию [репозитория Plexus Universe](https://github.com/craftimru/plexus-universe), затем выполните из неё:

```sh
python -X utf8 scripts/project_graph.py update --map /path/to/existing/project_graph
```

Нельзя просто заменить рабочую папку картой из репозитория: это демо. `update` переносит только инструмент и инструкции, сохраняет `graph_content.py`, `graph_edit.json`, журнал, резервную копию, изображения и кеш дат. Собранные данные обновляются после успешной сборки. При ошибке заменённые файлы инструмента и данные откатываются; запись параллельно с другой операцией запрещена блокировкой. Команда не меняет содержимое узлов и не подтверждает человеческие правки за агента.

Папка карты может по-прежнему называться `tools/project_graph` или `tools/project-universe-graph` — смена названия продукта не требует перемещения рабочих файлов.
